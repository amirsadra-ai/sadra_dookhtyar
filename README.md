# دوخت‌یار — وب‌سایت معرفی (نسخهٔ ۱.۱.۰)

وب‌سایت معرفی محصول «دوخت‌یار» — فارسی، راست‌چین، موبایل‌محور، بدون بکاند.
دریافت درخواست‌ها با **پیامک گوشی کاربر** انجام می‌شود: فرم پر می‌شود، دکمهٔ «ثبت درخواست»
باز کردن برنامهٔ پیامک گوشی را با متن آمادهٔ کامل برمی‌انگیزد و کاربر فقط دکمهٔ ارسال را می‌زند.

## ساختار

```
dokhtyar-site/
├── src/            سورس سایت (Next.js 16 + Tailwind 4 + framer-motion)
├── public/         فونت وزیرمتن، لوگو، تصویر OG
├── out/            ← نسخهٔ استاتیک از قبل بیلدشده — همین پوشه برای انتشار آماده است
├── docs/           مستندات کامل (INTEGRATION.md)
└── package.json
```

## اجرای محلی

```bash
npm install     # یا bun install
npm run dev     # http://localhost:3000
```

## انتشار روی GitHub Pages (یا هر هاست استاتیک)

سریع‌ترین راه: محتوای پوشهٔ `out/` را همان‌طور که هست آپلود کنید — نیازی به نصب چیزی نیست.

اگر خواستید خودتان بیلد بگیرید یا تغییری داده‌اید:

```bash
npm install
npm run build:static        # خروجی در out/   (لینوکس/مک)
```

در ویندوز (PowerShell):

```powershell
$env:STATIC_EXPORT="1"; npm run build
```

اگر سایت زیر زیرمسیر منتشر می‌شود (مثل `username.github.io/dokhtyar/`) هنگام بیلد
`NEXT_PUBLIC_BASE_PATH=/dokhtyar` را هم ست کنید. برای دامنهٔ اختصاصی یا صفحهٔ کاربر لازم نیست.

## تغییر شمارهٔ گیرندهٔ پیامک

شمارهٔ فعلی: **۰۹۳۳۰۵۹۲۴۱۲** (+989330592412)

در فایل `src/components/marketing/demo-cta.tsx` دو ثابت بالای فایل را ویرایش کنید:

```ts
const OWNER_SMS_NUMBER = "+989330592412";   // پیوند sms: (فرمت بین‌المللی)
const OWNER_SMS_NUMBER_FA = "۰۹۳۳ ۰۵۹ ۲۴۱۲"; // نمایش در صفحه
```

سپس دوباره `npm run build:static` بزنید تا `out/` به‌روز شود.

## نحوهٔ ساخت متن پیامک

متن بر اساس الگوی ثابت و فیلدهای فرم در `src/lib/sms.ts` ساخته می‌شود؛
فیلدهای اختیاریِ خالی (شهر/نوع فعالیت/توضیحات) کل جملهٔ خودشان حذف می‌شوند،
توضیحات چندخطی با حفظ کامل نیم‌فاصله و خطوط می‌آید و شمارهٔ موبایل در متن تکرار نمی‌شود.
تست‌های کامل ۵ سناریو: `bun run scripts/test-sms-body.ts`

سازگاری پیوند `sms:` برای iOS (`&body`) و اندروید (`?body`) داخل همین ماژول انجام می‌شود
و هیچ پیامکی خودکار ارسال نمی‌شود؛ ارسال نهایی با کاربر است.
